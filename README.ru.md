# QQ Versions

QQ Versions — это историческое зеркало официальных установщиков QQ. Репозиторий архивирует доступные пакеты для Windows, macOS и Linux в GitHub Releases, чтобы старые версии было проще находить, скачивать и проверять.

**Языки**: [中文](README.md) | [English](README.en.md) | [Français](README.fr.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | Русский | [Español](README.es.md)

## Скачать старые версии

Рекомендуемые страницы:

- GitHub Pages: <https://rodert.github.io/qq-versions/>
- GitHub Releases: <https://github.com/Rodert/qq-versions/releases>

Откройте страницу GitHub Pages или GitHub Releases, выберите нужную версию и скачайте файл для своей операционной системы:

- Windows: `.exe`
- macOS: `.dmg`
- Linux: `.deb`, `.rpm`, `.AppImage`

В каждый Release обычно добавляется `SHA256SUMS.txt` для проверки целостности файлов.

## Как использовать

1. Откройте <https://rodert.github.io/qq-versions/>.
2. Отфильтруйте пакеты по Windows, macOS или Linux.
3. Нажмите на нужный файл, чтобы скачать его.
4. Запустите установщик или установите пакет стандартным способом для вашей системы.

Примеры для Linux:

```bash
sudo dpkg -i QQ*.deb
```

```bash
sudo rpm -i QQ*.rpm
```

```bash
chmod +x QQ*.AppImage
./QQ*.AppImage
```

Пример проверки:

```bash
sha256sum -c SHA256SUMS.txt
```

## Назначение репозитория

У этого репозитория одна задача: организовать и публиковать исторический индекс официальных установщиков QQ. Он полезен, если нужно:

- Скачать старый установщик QQ.
- Сохранить пакеты для разных операционных систем за один период.
- Проверить целостность установщика через SHA256.
- Просматривать QQ Releases через более удобную страницу загрузок.

Права на установщики QQ принадлежат Tencent. Этот репозиторий предоставляет только исторический индекс и архив загрузок.
